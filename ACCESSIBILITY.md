# Accessibility

Current (M1):

- Full keyboard control of flight; UI buttons for every keyboard action.
- Pause: time warp controls always available; the game never requires
  reflexes faster than the player's chosen warp.
- Scalable text: UI uses rem-relative sizes; browser zoom works.
- Machine-readable perf overlay (F3) honest to real frame pacing.

Committed for M3–M5 (tracked in FEATURES.md):

- Remappable bindings; colorblind-safe palette audit for map/HUD accents;
  high-contrast mode; adjustable UI scale slider; reduced-motion option
  (disables camera shake/starfield twinkle); subtitle/caption channel for
  audio cues; simplified-terminology toggle alongside scientific terms.
